# 手机操作手册

> 这份是**操作规范**，不是人格。人格看 `roles/小鲸鱼.md`。
> 要动手机（模拟器）之前先过一遍这里，别凭感觉来。

---

## 一、你手上到底有什么

你**有** `mcp__android__*` 这一整套，13 个，别再说"我没有点击工具"：

| 工具 | 干什么 | 注意 |
|---|---|---|
| `init` | 连接设备 | serial 固定 `127.0.0.1:16384`，一次就够 |
| `device_list` | 看设备在不在 | 连不上时先跑这个 |
| `info` | 分辨率 / 当前 App / 屏幕亮不亮 | 比截图省一百倍，先问它 |
| `screenshot` | 截图（900×1600 原图） | **贵**，一轮最多 1 张 |
| `dump_hierarchy` | 拿界面结构（XML 文本） | 便宜，优先用它 |
| `click` | 点坐标 | 坐标就是 900×1600 里的像素，不用换算 |
| `long_click` | 长按 | 弹菜单用 |
| `swipe` | 任意方向滑 | 要传起止坐标 |
| `swipe_up` / `swipe_down` | 上滑 / 下滑 | 刷 feed 用这个 |
| `press_key` | 返回 / Home / 电源 | `back` `home` |
| `send_text` | 输入文字 | 中文直接发，走输入法 |
| `app_start` / `app_current` | 启动 / 查当前 App | 换 App 前后各查一次 |
| `xpath_click` / `xpath_exists` | 按 XPath 找元素 | **只有标准控件 App 能用**，见下 |

## 二、坐标怎么算

- 屏幕就是 **900 × 1600**，`click` 的 x/y 直接用这个尺度的像素
- 截图也是 900 × 1600，**你看到多少点多少，不用缩放**
- 圆心大约在 (450, 800)
- 底部 tab 栏在 y ≈ 1520～1600
- 拿不准就先 `screenshot` 看一眼，再按截图上的位置点

## 三、两个 App 的坑（最要紧）

**B 站 `tv.danmaku.bili`** 和 **小黑盒 `com.max.xiaoheihe`** 的界面是自绘的，**UI 树里没有文字**：

- `dump_hierarchy` 拿回来一大堆空节点，找不到"评论""点赞"这些字
- 所以 **`xpath_click` / `xpath_exists` 按文字找，在这两个 App 里永远失败**
- 这两个 App 只能用：`screenshot` 看一眼 → 按坐标 `click`
- **别在这两个 App 上死磕 xpath**，磕三轮就换截图+坐标，不然就是白烧钱

其他 App（设置、浏览器、系统界面）通常有标准控件，`dump_hierarchy` + `xpath` 能用，优先用它们（便宜又准）。

## 四、操作守则

1. **一次只做一件事**：点完 → 看一眼结果（`info` 或 `dump_hierarchy`）→ 再决定下一步。别连着瞎点。
2. **点之前先确认在哪个 App**：`app_current`，不在目标 App 就先 `app_start`。
3. **点了没反应，别重复点**：等 1～2 秒再看一次，连续点会点到下一屏的东西上。
4. **返回用 `press_key back`**，别乱点左上角（不同页面位置不一样）。
5. **截图是贵的**：能用 `dump_hierarchy` / `info` 拿到的信息绝不截图；一轮最多 1 张。
6. **不确定就停下来问**，不要硬编一个动作然后说"我点不了"——你有工具，说点不了前先确认自己调用了没有。
7. **动作做完写清楚**：做了什么、看到什么、下一步打算干什么。别只回"嗯"。

## 五、发布守则（硬规矩）

**任何要发出去的东西，发之前必须让主人过目点头。**

- B 站：投稿、发动态、发评论、改简介 —— 全部先给主人看
- 小黑盒：发帖、评论、点赞连着刷 —— 发内容前先给主人看
- 微信 / QQ 群发消息同理
- 只点赞、只浏览（不发内容、不改资料）可以自己来

主人说"发吧"才发。没说就只做出来放着。

## 六、连不上怎么办

1. `device_list` 看设备在不在
2. 不在 → 告诉主人「模拟器没起来」，让他开，或者自己跑
   `F:\Program Files\Netease\MuMu\nx_main\MuMuManager.exe control -v 0 launch`
3. 设备在但连不上 → `adb connect 127.0.0.1:16384`
4. 还是不行 → 别反复重试，报告情况

## 七、别做的事

- 别自己改系统设置（网络、账号、权限）
- 别点付费/授权弹窗
- 别翻手机里的私人相册、聊天记录
- 别卸载、别清数据、别格式化
- 模拟器崩了别自己重装
